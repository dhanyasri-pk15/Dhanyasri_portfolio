# Dhanyasri P K — Lavender AI Portfolio

A responsive one-page portfolio built with HTML, CSS, and vanilla JavaScript. This enhanced lavender edition includes soft gradients, floating background glows, scroll-reveal animations, interactive project cards, mobile navigation, and a bundled resume PDF.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser. (VS Code users can also use the Live Server extension.)
3. The Resume button opens `Dhanyasri-Resume.pdf`. Replace that PDF if your resume changes.

## Before publishing
- Confirm experience dates and project descriptions are accurate and suitable for public sharing.
- Add public GitHub repository/demo links only where you are allowed to share the code.
- Check the site on mobile and desktop.
- Never publish confidential employer code, customer information, credentials, or internal diagrams.

## Publish with GitHub Pages
1. Create or open your GitHub repository (for example, `Dhanyasri_portfolio`).
2. Upload the contents of this folder to the repository root.
3. In repository Settings → Pages, select deploy from the `main` branch and root folder.
4. Wait for GitHub Pages to publish the site.

No build tools or backend are required. Google Fonts load online; system fonts are used if they are unavailable.
